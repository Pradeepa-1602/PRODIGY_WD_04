# Automated Personal Portfolio Deployment on AWS

A CI/CD project that automates the build and deployment of a personal portfolio website using Jenkins, Docker, GitHub, and AWS EC2.

## Features

* Automated CI/CD pipeline
* GitHub source code integration
* Automated application build
* Docker containerization
* AWS EC2 deployment
* Reduced manual deployment effort

## Technologies

* HTML, CSS, JavaScript
* Git, GitHub
* Jenkins
* Docker
* AWS EC2

## Deployment Flow

`GitHub → Jenkins → Docker → AWS EC2`

## Project Objective

To automate the deployment process and gain practical experience in DevOps, CI/CD, Docker, Jenkins, and AWS.
